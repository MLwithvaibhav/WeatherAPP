# 🌦️ Weather App

A simple and responsive weather application built using HTML, CSS, and JavaScript. It fetches real-time weather data using the OpenWeather API and stores recent searches in local storage.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature
- ☁️ Weather condition
- 💧 Humidity information
- 🌬️ Wind speed
- 📊 Atmospheric pressure
- 🥵 Feels Like temperature
- 🕒 Search history
- 🗑️ Clear search history
- 📱 Responsive UI

## ▶️ Getting Started

1. Clone the repository

```bash
git clone https://github.com/MLwithvaibhav/Weather-App.git
```

2. Open `index.html`

3. Add your OpenWeather API key

```javascript
const API_KEY = "YOUR_API_KEY";
```

4. Run the project.
